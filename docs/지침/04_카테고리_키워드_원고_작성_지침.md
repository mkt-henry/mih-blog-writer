# 카테고리 키워드 원고 작성 지침

> **적용 분기:** 카테고리 키워드 원고 전용. 특정 인물 1명 섭외 원고는 이 문서가 아니라 `01 → 02 → 03`을 따른다. **02와 04를 동시에 따르지 않는다.** 자료 조사도 이 문서 안에 포함돼 있으므로 카테고리 원고에서는 `01_자료_수집_지침.md`를 보지 않는다. 분기 판단은 `00_개요.md` 참고.

## 목적

이 지침은 특정 아티스트 1명을 섭외하는 원고가 아니라, 네이버 검색에서 `행사공연`, `개그맨섭외`, `래퍼섭외`, `유튜버섭외`처럼 넓은 섭외 카테고리 키워드로 상위 노출을 목표로 하는 원고를 작성할 때 사용한다.

카테고리 원고의 목표는 아래 3가지다.

- 검색자가 지금 찾는 섭외 유형을 빠르게 이해하게 한다.
- 어떤 행사에 어떤 출연자군이 맞는지 비교 기준을 제공한다.
- 메이드인헤븐으로 문의해야 하는 이유와 문의 정보를 명확히 남긴다.

## 적용 대상

사용자가 아래처럼 요청하면 이 지침을 우선 적용한다.

- `행사공연 원고 써줘`
- `개그맨섭외 키워드로 블로그 글 만들어줘`
- `래퍼섭외 상위노출 원고`
- `유튜버섭외 원고`
- `기업행사공연`, `축제공연섭외`, `MC섭외`, `인플루언서섭외`처럼 특정 인물이 아닌 섭외 카테고리 요청

특정 인물명이 함께 있으면 기존 `01_자료_수집_지침.md`, `02_원고_작성_지침.md`, `03_원고_검토_지침.md`를 우선 적용한다.

## 기존 인물 원고와 다른 점

| 구분 | 인물 섭외 원고 | 카테고리 키워드 원고 |
|---|---|---|
| 메인 키워드 | `아티스트명 섭외` | `행사공연`, `개그맨섭외`, `래퍼섭외`, `유튜버섭외` 등 |
| 제목 시작 | `[아티스트명 섭외]` | `[메인키워드]` |
| 핵심 내용 | 해당 인물의 프로필·활동·행사 적합성 | 섭외 유형의 의미·행사별 선택 기준·문의 절차 |
| 표 구성 | 프로필 표 | 카테고리 정보 표 또는 섭외 기준 표 |
| 이미지 출처 | `출처 - [아티스트명] 공식 SNS` | `출처 - 메이드인헤븐 공식 자료` |
| 사실 검증 | 인물 프로필 중심 | 시장/행사 유형/예시 출연자/최근 트렌드 중심 |

## 자료 조사 원칙

카테고리 키워드도 학습 데이터만으로 쓰지 않는다. 검색 의도, 최근 행사 트렌드, 예시 출연자, 영상 URL은 반드시 웹 검색으로 확인한다.

### 필수 검색 세트

아래 검색을 최소 5회 이상 실행한다. 현재 연도는 반드시 `2026`으로 넣는다.

1. `"[메인키워드] 행사 섭외"`
2. `"[메인키워드] 기업 행사 축제 2026"`
3. `"[메인키워드] 섭외 비용 출연료"`
4. `"[메인키워드] 추천 출연자"`
5. `"[메인키워드] 유튜브 공식 영상"`
6. `"[메인키워드] 최신 트렌드 2026"`

필요하면 아래처럼 키워드별 보조 검색을 추가한다.

- `행사공연`: `기업 행사 공연 추천`, `축제 공연 섭외`, `행사 공연팀 종류`
- `개그맨섭외`: `개그맨 MC 섭외`, `코미디언 기업행사 섭외`, `개그맨 토크쇼 행사`
- `래퍼섭외`: `래퍼 축제 섭외`, `힙합 공연 섭외`, `대학축제 래퍼 공연`
- `유튜버섭외`: `유튜버 브랜드 행사 섭외`, `크리에이터 토크콘서트 섭외`, `인플루언서 행사 출연`

### 반영 가능한 정보

- 2개 이상 출처에서 일치하는 행사 유형, 최근 활동 흐름, 대표 사례
- 공식 채널 또는 언론 기사로 확인되는 예시 출연자 활동
- 실제 존재가 확인된 유튜브 영상 URL 2개
- 섭외 비용의 구체 금액이 아닌, 비용을 좌우하는 변수

### 금지 정보

- 확인되지 않은 출연료 단정
- 특정 아티스트를 보유 명단처럼 표현
- 독점 섭외, 100% 섭외 가능, 최저가 보장 같은 과장
- 단일 출처만 있는 예시 출연자를 확정 추천처럼 나열
- 논란, 건강, 계약 상태 등 민감한 정보를 홍보 문장에 불필요하게 확대

## 제목 규칙

형식은 아래를 따른다.

```md
[메인키워드] + 검색 의도 답변 + 타겟 행사 2~3개
```

예시:

- `[행사공연] 기업 행사와 지역 축제에 맞는 공연팀 섭외 가이드`
- `[개그맨섭외] 분위기를 살리는 MC·토크쇼·기업 행사 섭외`
- `[래퍼섭외] 대학 축제와 브랜드 행사에 맞는 힙합 공연 섭외`
- `[유튜버섭외] 브랜드 캠페인과 토크 콘서트 크리에이터 섭외`

권장 기준:

- 30~60자
- 대괄호 안에는 메인 키워드를 정확히 넣는다.
- 제목에 `섭외`, `행사`, `공연`, `기업`, `축제`, `브랜드`, `토크` 같은 검색 보조어를 자연스럽게 포함한다.

## 본문 구조

본문은 2,000~2,800자를 권장하고, 최대 3,000자를 넘기지 않는다. HTML 구조와 CTA 규칙은 `SKILL.md`와 `AGENTS.md`의 공통 규칙을 그대로 따른다.

### 1. 도입부

300~500자 안에서 AEO 정답 노드를 만든다.

- 메인 키워드가 무엇을 의미하는지
- 어떤 행사 담당자가 찾는 키워드인지
- 섭외할 때 가장 먼저 정리해야 할 항목이 무엇인지
- 문의 경로가 메이드인헤븐이라는 점

### 2. 카테고리 정보 표

기존 프로필 표 대신 아래 항목을 담은 정보 표를 사용한다.

- 검색 키워드
- 섭외 대상
- 적합 행사
- 핵심 장점
- 확인 포인트
- 문의 준비 자료

표 비율은 기존 프로필 표와 동일하게 22% : 78%를 사용한다.

### 3. 행사 방향 3가지

왼쪽 세로선 박스 3행으로 구성한다.

예시:

- `① 오프닝 분위기 형성`
- `② 참여형 프로그램 구성`
- `③ 브랜드 메시지 연결`

키워드별로 방향을 구체화한다.

- `행사공연`: 오프닝 공연, 축하 공연, 관객 참여형 공연
- `개그맨섭외`: MC 진행, 토크쇼, 분위기 전환
- `래퍼섭외`: 힙합 라이브, 대학축제 피크타임, 브랜드 젊은 이미지
- `유튜버섭외`: 토크 콘서트, 팬밋업, 숏폼·브랜드 콘텐츠 연계

### 4. 적합 행사 유형 4종

2열 표로 구성한다.

왼쪽 열:

- 행사 유형

오른쪽 열:

- 잘 맞는 이유

카테고리 키워드에서는 행사 유형이 곧 검색자의 의도이므로, 표가 중복되지 않도록 본문에서는 상세 설명을 반복하지 않는다.

### 5. 섭외 전 확인 포인트 3가지

왼쪽 세로선 박스 3행으로 구성한다.

필수 포함 항목:

- 예산과 희망 일정
- 행사 성격과 관객층
- 촬영, 송출, 2차 활용 여부

키워드별 보조 항목:

- 공연형 키워드: 음향, 무대, 대기실, 리허설
- MC/개그맨 키워드: 진행 대본, 수위, 애드리브 가능 범위
- 래퍼 키워드: 셋리스트, 음원 MR, 관객 스탠딩 여부
- 유튜버 키워드: 콘텐츠 활용 범위, 브랜드 노출 방식, 팬 응대 범위

### 6. 비용 안내

구체 금액은 확인된 자료가 없으면 쓰지 않는다.

대신 비용을 좌우하는 변수를 설명한다.

- 출연자 인지도
- 행사 날짜와 지역
- 공연/토크/MC 등 출연 형식
- 리허설과 체류 시간
- 촬영·송출·광고 2차 활용 여부

표현 예시:

```md
출연료는 고정 금액으로 단정하기 어렵고,
출연자 인지도, 행사 일정, 지역, 프로그램 구성,
촬영 활용 범위에 따라 달라집니다.
```

### 7. 참고 영상

유튜브 URL은 항상 정확히 2개를 넣는다.

- `https://www.youtube.com/watch?v=` 형식만 사용
- iframe/embed 금지
- 카테고리와 직접 관련 있는 공식 채널 또는 검증 가능한 영상만 사용
- 본문에는 `raw URL`, `iframe`, `스마트에디터 호환` 같은 발행자용 표현을 쓰지 않는다.

카테고리 키워드에서 특정 대표자가 없을 경우, 아래 기준으로 2개를 고른다.

- 예시 출연자 공식 채널 영상
- 방송사/행사 주최 측 공식 영상
- 브랜드 캠페인 공식 영상
- 카테고리 특성을 보여주는 공연·토크·콘텐츠 영상

### 8. CTA

CTA는 인물 원고와 동일하다.

- 에이전시명: 메이드인헤븐
- **명함 이미지는 원고 본문에 직접 넣지 않는다** (모아보기가 자동 합성).
- 카카오톡 링크: `https://open.kakao.com/o/snG6VXti`
- CTA 문구 영역에는 카카오 링크가 들어가는 `<p>` 만 배치한다 — 모아보기가 그 직전에 명함 이미지를 끼워넣는다.

### 9. 해시태그와 태그

해시태그 단락:

- 20개 이상
- 메인 키워드, 유사 키워드, 행사 유형, 문의 키워드 포함

태그:

- 10~17개
- 3단 구성
  - 핵심 키워드: `행사공연`, `행사공연 섭외`
  - 행사 유형: `기업행사`, `지역축제`, `브랜드행사`
  - 연관 키워드: `공연팀`, `MC섭외`, `크리에이터섭외`

## 이미지 출처 표기

카테고리 키워드 원고는 특정 아티스트 공식 이미지가 중심이 아니므로, 이미지 출처 표기는 아래 문구로 정확히 4개 사용한다.

```html
<p class="se-text-paragraph se-text-paragraph-align-center" style="" id="SE-srcN"><span style="color:#999999;" class="se-fs-fs13 se-ff- ">출처 - 메이드인헤븐 공식 자료</span></p>
```

아래 표현은 사용하지 않는다.

- `출처 - 공식 SNS`
- `출처 - 네이버`
- `출처 - 기사`
- `이미지 준비 중`
- `사진 삽입 위치`

## 메인 키워드 밀도

- 메인 키워드는 본문 전체에 10~20회 자연스럽게 배치한다.
- 띄어쓰기 변형은 보조로만 사용한다.
  - 예: 메인 키워드가 `개그맨섭외`라면 `개그맨 섭외`도 일부 사용 가능하지만, 검수 기준은 `개그맨섭외`를 중심으로 한다.
- 문장마다 반복하지 않는다.
- CTA, 표, 해시태그, 태그까지 포함해 과도하게 보이지 않도록 본문 흐름에 분산한다.

## 파일명 규칙

```md
output/YYYY-MM-DD/{agency_slug}/[메인키워드]_[최종 제목].html
```

`{agency_slug}`: `mih_speaker` / `mih_casting` / `mih_agency` 중 발행 계정. 사용자가 명시하지 않았으면 어디에 올릴지 먼저 확인한다.

예시:

```md
output/2026-05-06/mih_casting/개그맨섭외_[개그맨섭외] 분위기를 살리는 MC·토크쇼·기업 행사 섭외.html
```

Windows 금지 문자(`\ / : * ? " < > |`)는 공백 또는 `-`로 치환한다. 대괄호 `[]`, 쉼표 `,`는 그대로 둔다.

> **모아보기 반영:** 새 원고를 저장한 뒤 `npm run publish "<html-path>"`를 실행하면 Supabase에 업로드되고 배포 사이트에서 즉시 보인다.

## 검토 체크리스트

- [ ] 제목이 `[메인키워드]`로 시작하는가
- [ ] 본문 텍스트가 2,000~2,800자인가
- [ ] 메인 키워드가 10~20회 자연스럽게 등장하는가
- [ ] 특정 아티스트 보유/독점/확정 가능처럼 오해될 표현이 없는가
- [ ] 비용을 구체 금액으로 단정하지 않았는가
- [ ] 카테고리 정보 표 1개가 있는가
- [ ] 행사 방향 박스 3개가 있는가
- [ ] 적합 행사 유형 4종 표가 있는가
- [ ] 섭외 전 확인 포인트 3개가 있는가
- [ ] 유튜브 URL이 정확히 2개인가
- [ ] 이미지 출처 표기가 정확히 4개이며 `출처 - 메이드인헤븐 공식 자료` 형식인가
- [ ] 모든 본문 단락이 `se-text-paragraph` 구조인가
- [ ] 모든 table에 `table-layout:fixed`가 있는가
- [ ] 명함 이미지와 카카오톡 링크가 정확한가
- [ ] 해시태그가 20개 이상인가
- [ ] 파일이 `output/YYYY-MM-DD/{agency_slug}/` 폴더에 저장되었는가 (발행 계정 슬러그 서브폴더 필수)

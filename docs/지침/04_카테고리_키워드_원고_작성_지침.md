# 카테고리 키워드 원고 작성 지침

> **적용 분기:** 카테고리 키워드 원고 전용. 특정 인물 1명 섭외 원고는 이 문서가 아니라 `01 → 02 → 03`을 따른다. **02와 04를 동시에 따르지 않는다.** 자료 조사도 이 문서 안에 포함돼 있으므로 카테고리 원고에서는 `01_자료_수집_지침.md`를 보지 않는다. 분기 판단은 `00_개요.md` 참고.

## 목적

이 지침은 특정 아티스트 1명을 섭외하는 원고가 아니라, 네이버 검색에서 `행사공연`, `개그맨섭외`, `래퍼섭외`, `유튜버섭외`처럼 넓은 섭외 카테고리 키워드로 상위 노출을 목표로 하는 원고를 작성할 때 사용한다.

2026년 6월 기준 네이버 검색은 AI 브리핑·AI탭을 통해 복합 질문에 답하고, 블로그·카페·지식iN 등 UGC 창작자 콘텐츠를 AI 답변 출처로 더 적극 활용하는 방향으로 고도화되고 있다. 카테고리 원고는 단순 키워드 반복보다 **카테고리 정의, 행사별 선택 기준, 비용 변수, 신청 절차**를 답변형으로 명확히 제시해야 한다.

카테고리 원고의 목표는 아래 3가지다.

- 검색자가 지금 찾는 섭외 유형을 빠르게 이해하게 한다.
- 어떤 행사에 어떤 출연자군이 맞는지 비교 기준을 제공한다.
- 메이드인헤븐으로 문의해야 하는 이유와 문의 정보를 명확히 남긴다.

## 적용 대상

사용자가 아래처럼 요청하면 이 지침을 우선 적용한다.

- `행사공연 원고 써줘`
- `개그맨섭외 키워드로 블로그 글 만들어줘`
- `래퍼섭외 상위노출 원고`
- `유튜버섭외 원고`
- `기업행사공연`, `축제공연섭외`, `MC섭외`, `인플루언서섭외`처럼 특정 인물이 아닌 섭외 카테고리 요청

특정 인물명이 함께 있으면 기존 `01_자료_수집_지침.md`, `02_원고_작성_지침.md`, `03_원고_검토_지침.md`를 우선 적용한다.

## 자료 조사 원칙

카테고리 키워드도 학습 데이터만으로 쓰지 않는다. 검색 의도, 최근 행사 트렌드, 예시 출연자, 영상 URL은 반드시 웹 검색으로 확인한다.

조사 결과를 원고에 반영할 때는 아래 기준을 따른다.

- 최근 트렌드는 2026년 기준으로 확인하고, 오래된 사례만으로 원고를 구성하지 않는다.
- 단일 출처의 주장을 확정 사실처럼 쓰지 않는다.
- 비용 정보는 구체 금액을 단정하지 않고, 출연자 인지도·일정·지역·공연 시간·촬영/송출 여부 같은 변수를 설명한다.
- 상위 글에 흔한 일반론을 그대로 반복하지 말고, 메이드인헤븐의 행사 실무 관점에서 선택 기준을 제시한다.

### 필수 검색 세트

아래 검색을 최소 5회 이상 실행한다. 현재 연도는 반드시 `2026`으로 넣는다.

1. `"[메인키워드] 행사 섭외"`
2. `"[메인키워드] 기업 행사 축제 2026"`
3. `"[메인키워드] 섭외 비용 출연료"`
4. `"[메인키워드] 추천 출연자"`
5. `"[메인키워드] 유튜브 공식 영상"`
6. `"[메인키워드] 최신 트렌드 2026"`

필요하면 아래처럼 키워드별 보조 검색을 추가한다.

- `행사공연`: `기업 행사 공연 추천`, `축제 공연 섭외`, `행사 공연팀 종류`
- `개그맨섭외`: `개그맨 MC 섭외`, `코미디언 기업행사 섭외`, `개그맨 토크쇼 행사`
- `래퍼섭외`: `래퍼 축제 섭외`, `힙합 공연 섭외`, `대학축제 래퍼 공연`
- `유튜버섭외`: `유튜버 브랜드 행사 섭외`, `크리에이터 토크콘서트 섭외`, `인플루언서 행사 출연`

### 반영 가능한 정보

- 2개 이상 출처에서 일치하는 행사 유형, 최근 활동 흐름, 대표 사례
- 공식 채널 또는 언론 기사로 확인되는 예시 출연자 활동
- 실제 존재가 확인된 유튜브 영상 URL 2개
- 섭외 비용의 구체 금액이 아닌, 비용을 좌우하는 변수

### 금지 정보

- 확인되지 않은 출연료 단정
- 특정 아티스트를 보유 명단처럼 표현
- 독점 섭외, 100% 섭외 가능, 최저가 보장 같은 과장
- 단일 출처만 있는 예시 출연자를 확정 추천처럼 나열
- 논란, 건강, 계약 상태 등 민감한 정보를 홍보 문장에 불필요하게 확대

## 제목 규칙

형식은 아래를 따른다.

```md
[메인키워드] + 검색 의도 답변 + 타겟 행사 2~3개
```

예시:

- `[행사공연] 기업 행사와 지역 축제에 맞는 공연팀 섭외 가이드`
- `[개그맨섭외] 분위기를 살리는 MC·토크쇼·기업 행사 섭외`
- `[래퍼섭외] 대학 축제와 브랜드 행사에 맞는 힙합 공연 섭외`
- `[유튜버섭외] 브랜드 캠페인과 토크 콘서트 크리에이터 섭외`

권장 기준:

- 30~60자
- 대괄호 안에는 메인 키워드를 정확히 넣는다.
- 제목에 `섭외`, `행사`, `공연`, `기업`, `축제`, `브랜드`, `토크` 같은 검색 보조어를 자연스럽게 포함한다.

## 본문 구조

본문은 **해시태그 제외 3,800~6,000자**다. **3,800자 미달은 발행 불가**다. HTML 구조와 CTA 규칙은 `SKILL.md`와 `AGENTS.md`의 공통 규칙을 그대로 따른다.

> 분량은 같은 말을 늘려 채우는 게 아니라, 비용·일정·무대·행사 적합성·준비 항목을 **각각 다른 어휘로** 다뤄서 만든다. 반복은 감점 요인이다.

> **섹션 배치 요약 (순서 고정)**
> 1. 도입부 → 2. 카테고리 정보 표 → 이미지① → 3. 행사 방향 3가지 → 이미지② → 4. 적합 행사 유형 표 → 이미지③ → 5. 섭외 프로세스 → 6. 섭외 전 확인 포인트 → 7. FAQ → 8. 비용 안내 → 이미지④ → 9. 참고 영상 → 10. CTA → 해시태그

### 1. 도입부

300~500자 안에서 AEO 정답 노드를 만든다.

- 메인 키워드가 무엇을 의미하는지 **한 문장**으로 정의
- 어떤 행사 담당자가 찾는 키워드인지
- 섭외할 때 가장 먼저 정리해야 할 항목이 무엇인지
- 문의 경로가 메이드인헤븐이라는 점

**첫 문장에 메인 키워드를 반드시 포함한다.** 도입부 전체에서 메인 키워드는 2~3회 이내로 제한한다.

도입부에는 아래 답변형 문장 2개를 반드시 포함한다. 문장 구조는 바꿔도 되지만 정보는 빠뜨리지 않는다.

- `[메인키워드]는 [행사 유형 2~3개]에서 [무대/진행/콘텐츠 목적]을 해결하기 위한 섭외 키워드입니다.`
- `출연료와 가능 일정은 출연자 인지도, 행사 날짜, 지역, 진행 시간, 촬영·송출 여부에 따라 달라지므로 메이드인헤븐을 통해 조건 확인 후 진행합니다.`

### 4. 적합 행사 유형 4종

2열 표로 구성한다.

왼쪽 열:

- 행사 유형

오른쪽 열:

- 잘 맞는 이유

카테고리 키워드에서는 행사 유형이 곧 검색자의 의도이므로, 표가 중복되지 않도록 본문에서는 상세 설명을 반복하지 않는다.

### 5. 섭외 프로세스 단계별 안내 ★ 신규 필수

**4단계**를 왼쪽 세로선 박스 또는 번호 박스로 구성한다. 각 단계는 구체적인 행동 또는 확인 사항을 담는다.

```
① 초기 문의 및 일정 확인
② 후보 추천 및 조건 협의
③ 계약 및 준비 조율
④ 행사 당일 진행
```

단계별 설명에 **"비용", "출연료", "계약", "일정 조율"** 같은 절차적 의도 쿼리를 자연스럽게 포함한다. 검색자는 단순 섭외 방법만 아니라 **절차 전체**를 궁금해하기 때문이다.

### 6. 섭외 전 확인 포인트 3가지

왼쪽 세로선 박스 3행으로 구성한다.

필수 포함 항목:

- 예산과 희망 일정
- 행사 성격과 관객층
- 촬영, 송출, 2차 활용 여부

키워드별 보조 항목:

- 공연형 키워드: 음향, 무대, 대기실, 리허설
- MC/개그맨 키워드: 진행 대본, 수위, 애드리브 가능 범위
- 래퍼 키워드: 셋리스트, 음원 MR, 관객 스탠딩 여부
- 유튜버 키워드: 콘텐츠 활용 범위, 브랜드 노출 방식, 팬 응대 범위

### 7. 자주 묻는 질문 (FAQ) ★ 신규 필수

## 이미지 출처 표기 및 선택 방법

카테고리 키워드 원고의 이미지는 **DB에 이미 저장된 관련 아티스트 이미지**를 사용한다. 별도의 외부 이미지를 새로 수집하거나 업로드하지 않는다.

### 이미지 선택 원칙

- 키워드 카테고리와 관련 있는 아티스트 4명을 DB에서 선택한다.
- 아티스트 1명당 이미지 1장씩, 총 4장을 사용한다.
- 같은 아티스트의 이미지 4장을 모두 쓰지 않는다. 아티스트를 다양하게 섞어 카테고리의 폭을 보여준다.

### DB 이미지 URL 패턴

```
https://un1nlrbeiyjhkrdj.public.blob.vercel-storage.com/article-images/{ascii-slug}/img{N}.jpg
```

- `{ascii-slug}`: 아티스트 업로드 시 사용된 영문 소문자 슬러그 (예: `shortbox-official`, `itzy`, `mamamoo`)
- `{N}`: 1~4 중 하나

사용 가능한 아티스트 이미지는 아래 스크립트로 확인한다.

```bash
node -e "
import { createClient } from '@supabase/supabase-js';
import { config } from 'dotenv';
config({ path: '.env.local' });
const supabase = createClient(process.env.SUPABASE_URL, process.env.SUPABASE_SERVICE_ROLE_KEY);
const { data } = await supabase.from('articles').select('slug, person_name, html_content');
data.forEach(row => {
  const m = row.html_content.match(/src=\"(https:\/\/un1nlrbeiyjhkrdj[^\"]+)\"/);
  if (m) console.log(row.person_name, m[1]);
});
" --input-type=module
```

또는 `/keywords` 페이지에서 등록된 아티스트 목록을 참고한다.

### 출처 표기

이미지마다 해당 아티스트 이름으로 출처를 표기한다.

```html
<p class="se-text-paragraph se-text-paragraph-align-center" style="" id="SE-srcN"><span style="color:#999999;" class="se-fs-fs13 se-ff- ">출처 - [아티스트명] 공식 SNS</span></p>
```

아래 표현은 사용하지 않는다.

- `출처 - 메이드인헤븐 공식 자료`
- `출처 - 네이버`
- `출처 - 기사`
- `이미지 준비 중`
- `사진 삽입 위치`

## 메인 키워드 밀도

- **목표 범위: 본문(해시태그 제외) 1000자당 3~5회.** 절대 횟수가 아니라 밀도로 관리한다. 글이 길어지면 횟수는 늘어도 밀도는 유지돼야 한다. 5회 초과는 발행 불가다.
- **`섭외`가 들어간 해시태그는 7개 이하.** 태그에 키워드를 몰아넣는 것도 같은 반복 신호다.
- 각 섹션 제목(h2)에 메인 키워드를 포함하되, **전체 제목 중 최대 5/10개 이내**로 제한한다. 모든 제목에 키워드를 넣으면 오히려 의미 밀도가 희석된다.
- 메인 키워드 1회 등장 후 **다음 2~3문장 이상 다른 표현**을 사용한 뒤 다시 배치한다.
- 띄어쓰기 변형(`개그맨 섭외`)도 밀도 계산에 포함한다.
- 검색 상위 글의 문장 패턴을 복제하지 않는다. 행사 규모, 관객층, 무대 구성, 계약 전 확인사항처럼 이 글만의 판단 정보를 넣는다.

## 의미론적 연관어(LSI) 통합 — 코사인 유사도 강화 ★ 신규

단순 키워드 반복은 코사인 유사도를 높이지 못한다. 검색 엔진은 **메인 키워드와 함께 자주 등장하는 공기어(Co-occurring Terms)**를 기반으로 문서의 주제 적합도를 측정한다.

### 의무 통합 연관어 (키워드별)

각 카테고리 원고는 아래 LSI 연관어를 **본문에 자연스럽게 5개 이상** 포함해야 한다.

| 카테고리 키워드 | 필수 LSI 연관어 |
|---|---|
| 행사공연 | 공연팀, 출연료, 무대, 음향, 리허설, 행사 기획, 공연 시간, 축하 공연, 갈라쇼 |
| 개그맨섭외 | 코미디언, MC 진행, 애드리브, 진행 대본, 기업 행사, 토크쇼, 분위기 전환 |
| 래퍼섭외 | 힙합, 라이브, 셋리스트, MR, 스탠딩, 피크타임, 콜앤리스폰스, 떼창 |
| 유튜버섭외 | 크리에이터, 팬덤, 구독자, 콘텐츠, 브랜드 캠페인, 팬미팅, 바이럴 |
| MC섭외 | 사회자, 아나운서, 의전, 진행 대본, 행사 흐름, 패널 토론, 즉흥 대응 |
| 트로트섭외 | 지역 축제, 효도 콘서트, 라이브, 떼창, 미스터트롯, 미스트롯, 오디션 |

위 표에 없는 키워드의 경우 웹 검색으로 상위 블로그에서 함께 등장하는 단어 5개 이상을 파악해 통합한다.

### 적용 규칙

- LSI 단어들은 **문장 내에 자연스럽게** 배치한다. 별도 리스트로 나열하거나 표 셀에만 채워 넣지 않는다.
- 각 섹션마다 1~2개의 LSI 연관어가 포함되도록 분산한다.
- **동의어/유의어 활용**: 메인 키워드를 직접 반복하는 대신, 연관어로 의미를 보강한다.
  - 예: `래퍼섭외`를 반복하는 대신 "힙합 공연 섭외", "힙합 아티스트 섭외"로 변형

## 파일명 규칙

```md
output/YYYY-MM-DD/{agency_slug}/[메인키워드]_[최종 제목].html
```

`{agency_slug}`: `mih_speaker` / `mih_casting` / `mih_agency` 중 발행 계정. 사용자가 명시하지 않았으면 어디에 올릴지 먼저 확인한다.

예시:

```md
output/2026-05-06/mih_casting/개그맨섭외_[개그맨섭외] 분위기를 살리는 MC·토크쇼·기업 행사 섭외.html
```

Windows 금지 문자(`\ / : * ? " < > |`)는 공백 또는 `-`로 치환한다. 대괄호 `[]`, 쉼표 `,`는 그대로 둔다.

> **모아보기 반영:** 새 원고를 저장한 뒤 `npm run publish "<html-path>"`를 실행하면 Supabase에 업로드되고 배포 사이트에서 즉시 보인다.

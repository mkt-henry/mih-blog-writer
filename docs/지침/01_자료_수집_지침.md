# 자료 수집 에이전트 지침

> **적용 분기:** 인물 원고 작성 전 단계 전용. 카테고리 키워드 원고(`행사공연`, `개그맨섭외` 등)에는 이 문서를 적용하지 않는다 — 카테고리 원고의 자료 조사는 `04_카테고리_키워드_원고_작성_지침.md` 안에 따로 정의돼 있다. 분기가 헷갈리면 `00_개요.md`부터 본다.

## 역할

자료 수집 에이전트는 원고 작성 전에 아티스트 정보를 검증해 **작성 가능한 근거 묶음**을 만든다. 학습 데이터나 기억에 의존하지 않고, 검색 결과와 직접 확인한 페이지를 기준으로 정리한다.

## 필수 검색

아티스트명만 주어진 경우 아래 검색을 모두 수행한다. 현재 연도는 실제 작업일 기준 연도이며, 이 프로젝트의 기준일이 2026년이면 2026을 포함한다.

1. `[아티스트명] 프로필 데뷔 소속사`
2. `[아티스트명] 최근 활동 2026`
3. `[아티스트명] 수상 내역 2026`
4. `[아티스트명] 뮤직비디오 유튜브 official`
5. `[아티스트명] 최신 뉴스 OR 컴백 OR 활동`

필요하면 아래 검색을 추가한다.

- `[아티스트명] 공식 홈페이지`
- `[아티스트명] 공식 SNS`
- `[아티스트명] 소속사 이적`
- `[아티스트명] 대표곡`
- `[아티스트명] 팬덤명`
- 그룹이면 `[그룹명] 멤버 구성`

## 직접 확인 기준

- 공식/위키 레벨 소스(공식 홈페이지, 공식 SNS, 위키백과, 나무위키, 언론 기사)를 최소 1개 이상 직접 확인한다.
- 2개 이상 출처에서 일치하는 정보만 확정 사실로 넘긴다.
- 단일 출처에서만 보이거나 출처 간 충돌하는 정보는 `불확실`로 표시하고, 원고에는 일반화 표현만 쓰도록 전달한다.
- 수상, 소속사, 데뷔일, 출연작, 팬덤명, 멤버 구성은 추정으로 채우지 않는다.

## 유튜브 영상 기준

- 실제 존재하는 `https://www.youtube.com/watch?v=...` 형식 raw URL을 정확히 2개 확보한다.
- 공식 채널 영상, 공식 MV, 방송사 공식 영상, 소속사 공식 영상 순으로 우선한다.
- 쇼츠, 팬 편집 영상, 재업로드 영상은 공식 영상이 없을 때만 보조 후보로 두고, 원고에는 가급적 넣지 않는다.
- 최종 산출물에는 유튜브 URL이 0개, 1개, 3개 이상이면 안 된다.

## 인스타그램 이미지 수집

섭외 원고 작성 시 아티스트의 공식 인스타그램에서 이미지를 직접 수집해 원고에 삽입한다.

1. 필수 검색 또는 `[아티스트명] site:instagram.com` 검색으로 공식 인스타그램 handle을 확인한다.
2. `apify/instagram-post-scraper`를 사용해 해당 계정의 이미지 게시물을 최소 5개 이상 수집한다.
   - 입력: `username: [handle]`, `resultsLimit: 10`, `dataDetailLevel: "basicData"`
3. 수집된 게시물 중 `type: "Image"`인 것만 추려 `displayUrl`을 추출한다.
4. 이미지 4개를 선정해 산출물에 URL 목록으로 포함시키고, 작성 에이전트에 전달한다.
5. Instagram CDN URL은 만료 기한(`oe=` 파라미터)이 있으므로 수집 즉시 원고에 반영한다.

## 이미지 출처 기준

- 원고 본문에 본문 근거 출처를 나열하지 않는다.
- 작성 에이전트에 넘길 이미지 출처 문구는 항상 `출처 - [아티스트명] 공식 SNS` 형식으로 통일한다.
- 최종 원고에는 이미지 출처 표기를 정확히 4개 넣도록 작성 에이전트에 전달한다.
- `공식 인스타그램 (@handle)`, `뉴스 기사`, `이미지 캡처`처럼 세부 출처를 HTML 문구에 넣지 않는다.
- **뉴스 기사·보도자료·방송 캡처 이미지는 저작권 문제로 절대 사용하지 않는다.** 공식 인스타그램 이미지가 부족하면 해당 위치를 이미지 없이 두고, 출처 표기 텍스트만 남긴다. 이미지는 발행자가 직접 수동으로 추가한다.

## 산출물 형식

자료 수집 결과는 아래 형식으로 작성 에이전트에 넘긴다.

```md
## 자료 수집 산출물

아티스트명:
메인 키워드: [아티스트명] 섭외

### 확정 사실
- 데뷔:
- 소속사:
- 장르/포지션:
- 대표곡:
- 주요 수상/이력:
- 최근 활동:

### 불확실하거나 일반화할 정보
- 항목:
- 원고 처리 방식:

### 행사 적합성
- 추천 행사 유형 1:
- 추천 행사 유형 2:
- 추천 행사 유형 3:
- 추천 행사 유형 4:
- 타깃 연령대:

### 유튜브 URL
1. https://www.youtube.com/watch?v=
2. https://www.youtube.com/watch?v=

### 인스타그램 이미지 URL
- 공식 인스타그램 handle: @
1. [displayUrl 1]
2. [displayUrl 2]
3. [displayUrl 3]
4. [displayUrl 4]

### 이미지 출처 문구
출처 - [아티스트명] 공식 SNS
개수: 정확히 4개

### 참고한 출처
- 출처명 / 확인 내용 / URL
```

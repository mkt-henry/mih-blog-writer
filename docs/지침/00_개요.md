# 지침 사용 가이드

`docs/지침/` 폴더에는 4개의 지침 문서가 있다. 어떤 작업이든 시작 전에 이 문서를 먼저 보고 **자기 작업이 어느 분기에 속하는지** 확인한 뒤 해당 지침만 본다. 여러 지침을 동시에 따르지 않는다.

---

## 분기 결정

사용자 요청이 **특정 인물 1명**(아티스트·강연자·MC 등)을 섭외하는 원고인지, 아니면 **카테고리 키워드**(`행사공연`, `개그맨섭외`, `래퍼섭외`, `유튜버섭외` 등) 원고인지로 갈린다.

| 요청 형태 | 따라야 할 지침 |
|---|---|
| `[OOO 섭외 원고 써줘]` 처럼 **인물 1명** | `01 → 02 → 03` |
| `[행사공연 원고]` 처럼 **카테고리 키워드** | `04 → 03` |

이 외 분기는 없다. 인물명이 함께 들어 있더라도 `[래퍼섭외] 무대를 만드는 OOO`처럼 **카테고리가 메인 키워드**면 04를 따른다.

> **판단 기준:** 제목의 대괄호 `[]` 안에 들어갈 키워드가 인물명이면 인물 원고, 카테고리 키워드(`행사공연`, `개그맨섭외`, `래퍼섭외`, `유튜버섭외` 등)이면 카테고리 원고다.

---

## 주제 미지정 요청 (인물·키워드를 지정하지 않은 경우)

사용자가 특정 인물이나 카테고리 키워드 없이 그냥 `원고 써줘`, `몇 개 써줘`처럼 요청하면 아래 기본값으로 처리한다.

> **`계정별로 N개씩 써줘`처럼 개수만 지정한 요청은 활성 발행 계정 4개(`mih_speaker`/`mih_casting`/`mih_agency`/`other`) 전부를 대상으로 하며, `other`를 빠뜨리지 않는다.** `05_랜덤_키워드_셀렉트_지침.md`를 먼저 따른다.** 키워드 DB에서 발행·작성된 키워드를 제외하고 계정별로 랜덤 추출 → 사용자 확인 → `01 → 02 → 03` 순서다.

- **분기:** 기본은 **인물 섭외 원고**(`01 → 02 → 03`)다.
- **주제 성격은 발행 계정으로 결정한다.**
  - `mih_speaker` → 강연·강사·스피커 인물 (강연 섭외 원고)
  - 그 외(`mih_casting` / `mih_agency` / `other`) → 가수 등 연예인 섭외 원고
  - 발행 계정이 정해지지 않았으면 사용자에게 먼저 확인한다.
- **중복 제외 (필수):** 이미 다룬 인물/키워드는 다시 쓰지 않는다. 발행 완료분뿐 아니라 **발행 대기(미발행)분도 제외**한다.
  - 확인 범위: Supabase `articles` 테이블 전체(`published_at` 값이 있든 `null`(발행 대기)이든 무관) + `output/` 폴더 전체.
  - **계정(agency)을 불문하고 전체 범위에서 제외한다.** `mih_casting`에서 썼던 인물을 `other`에 다시 쓰는 것은 금지다. 어느 계정에서 발행·대기 중이든 동일하게 제외 대상이다.
  - 즉 한 번이라도 원고가 만들어진 인물/키워드는 후보에서 뺀다.
- 후보를 정한 뒤에는 인물 원고이므로 `01 → 02 → 03`을 그대로 따른다.

---

## 각 지침의 역할 한 줄 요약

- **01_자료_수집_지침.md** — 인물 원고를 쓰기 전에 웹 검색으로 사실을 검증해 작성자 에이전트가 쓸 근거 묶음을 만든다. **인물 원고에만 사용한다.**
- **02_원고_작성_지침.md** — 01의 산출물을 받아 인물 1명을 대상으로 SE3 HTML 원고를 만든다. **인물 원고 작성 전용.**
- **03_원고_검토_지침.md** — 완성된 HTML이 통과 기준을 충족하는지 점검한다. **인물·카테고리 원고 모두에 적용된다.**
- **04_카테고리_키워드_원고_작성_지침.md** — 카테고리 키워드 원고의 자료 조사, 작성, 구조 규칙을 한 문서에 모았다. 카테고리 원고는 01·02 대신 이 문서 하나로 작성을 끝낸다.
- **05_랜덤_키워드_셀렉트_지침.md** — `계정별로 N개씩 써줘`처럼 주제·개수만 지정한 요청에서, 키워드 DB의 미작성 후보를 계정별로 랜덤 추출한다. 후보 확정 후에는 인물 원고이므로 `01 → 02 → 03`으로 넘어간다.

---

## 혼동 금지

- **02와 04를 동시에 따르지 않는다.** 인물 원고면 02, 카테고리 원고면 04. 둘 사이에서 서로 베끼지 않는다.
- **01은 카테고리 원고에 적용하지 않는다.** 카테고리 원고의 자료 조사 절차는 04 안에 따로 정의돼 있다.
- **03은 두 분기 모두 적용된다.** 단, 분기에 따라 일부 항목이 다르다 — 03 안에서 "인물 원고만 / 카테고리 원고만" 표시된 항목을 본다.
- **공통 규칙은 `AGENTS.md`와 `SKILL.md`** 에 있다. 지침 내부에서 공통 규칙을 다시 정의하지 않고, 충돌이 생기면 AGENTS.md가 우선한다.

---

## 출력 위치

분기와 무관하게 모든 원고는 다음 경로에 저장한다.

```
output/YYYY-MM-DD/{agency_slug}/[slug]_[원고제목].html
```

`{agency_slug}`는 `mih_speaker` / `mih_casting` / `mih_agency` / `other` 중 하나. 발행 계정이 정해지지 않았으면 사용자에게 먼저 확인한다.

저장 후 `npm run publish "<html-path>"`를 한 번 실행하면 배포된 모아보기 사이트(`/`)에서 즉시 확인된다.

# 원고 검토 에이전트 지침

> **적용 분기:** 인물 원고와 카테고리 키워드 원고 모두에 적용된다. 단 일부 항목은 분기에 따라 다르므로, 본문에 표시된 *(인물 원고)* 또는 *(카테고리 원고)* 라벨을 따라 적용한다. 분기 판단은 `00_개요.md` 참고.

## 역할

원고 검토 에이전트는 완성된 HTML 파일이 프로젝트 지침을 충족하는지 확인한다. 문제가 있으면 통과시키지 않고 수정 항목을 구체적으로 남긴다.

## 검토 우선순위

1. 사실 오류와 출처 불명 단정
2. 유튜브 URL 개수와 형식
3. 네이버 SE3 HTML 구조
4. 이미지 삽입과 출처 표기 규칙
5. SEO 제목, 본문 구조, AI 인용 가능성, 키워드 밀도
6. CTA, 명함 이미지, 카카오톡 링크
7. 파일 저장 위치와 파일명

## 사실 검토

- 자료 수집 산출물에 없는 구체 사실이 원고에 추가되었는지 확인한다.
- 소속사, 데뷔, 수상, 출연작, 팬덤명, 멤버 구성은 자료 수집 산출물과 일치해야 한다.
- 카테고리 키워드 원고는 시장/행사 유형/예시 출연자/최근 트렌드가 자료 조사 결과와 일치해야 한다.
- 단일 출처 또는 충돌 정보는 단정 표현으로 쓰면 안 된다.
- 프로필 표에 있는 상세 리스트를 본문에서 반복 나열하면 수정 요청한다.

## 유튜브 검토

- 유튜브는 iframe 임베드가 정확히 2개인지 확인한다.
- `https://www.youtube.com/embed/VIDEO_ID` 형식의 iframe src가 실제 영상 ID를 포함해야 한다.
- `https://www.youtube.com/watch?v=` 형식의 raw URL 텍스트만 남아 있으면 실패 처리한다.
- 0개, 1개, 3개 이상이면 실패 처리한다.
- 본문 문장에 `iframe`, `raw URL`, `스마트에디터 호환`, `원본 URL만 남깁니다` 같은 발행자용 기술 설명이 노출되면 실패 처리한다.
- iframe 사이에 `<p><br></p>` 여백이 있는지 확인한다.

## 이미지 검토

- `📷 사진 N 삽입 위치` placeholder가 있으면 실패 처리한다.
- 인물 섭외 원고는 본문 이미지 `<img>`가 정확히 4개여야 한다. 명함 이미지, `business-card`, 카카오 링크 이미지는 이 개수에 포함하지 않는다.
- 인물 섭외 원고에서 본문 이미지가 0~3개이거나 5개 이상이면 실패 처리한다.
- 이미지 출처 표기는 정확히 4개여야 한다.
- 인물 섭외 원고는 각 이미지 바로 아래에 출처 표기가 붙어 있어야 하며, 이미지+출처 세트가 정확히 4개여야 한다.
- 인물 섭외 원고의 출처 문구는 이미지 소스에 따라 `출처 - [아티스트명] 공식 SNS` 또는 `출처 - [아티스트명] 공식 자료` 형식이어야 한다.
- 카테고리 키워드 원고의 출처 문구는 04 지침에 따라 `출처 - [아티스트명] 공식 SNS` 형식이어야 한다.
- `출처 —`, `출처-`, `공식 인스타그램 (@handle)`, 기사명, URL 등 다른 형식이 있으면 수정 요청한다.
- 출처 표기는 본문 근거 출처가 아니라 이미지 출처임을 전제로 검토한다. 인물 원고에서 출처 표기만 있고 실제 이미지가 없으면 실패 처리한다.
- 출처 표기는 가운데 정렬, `#999999`, `se-fs-fs13 se-ff-` 클래스여야 한다.
- 인물 원고의 본문 이미지 4개는 CTA/카카오 링크/해시태그 이전에 배치되어야 한다.
- 이미지는 본인이 나온 이미지여야 한다 (공식 인스타그램 우선, 부족하면 기타 이미지 허용).
- **보도자료 이미지만 사용 시 실패 처리한다.** 그 외 본인이 나온 이미지는 허용한다.
- 이미지 업로드 후 최종 HTML의 본문 이미지 src는 **Supabase 버킷 공개 URL**(`.../storage/v1/object/public/article-images/{slug}/img{N}.jpg`)이어야 한다. 외부 원본 URL이 남았거나 업로드 스크립트를 실행하지 않았으면 실패 처리한다.
- **Vercel Blob URL(`*.blob.vercel-storage.com`)은 실패 처리한다.** `check:article`이 `blob_image_src`로 잡는다.
- `data:image/...`, `src="image.png"`, 상대 경로 이미지는 실패 처리한다.

## HTML 구조 검토

- 일반 본문 단락이 단순 `<p>본문</p>`로 작성되어 있으면 실패 처리한다.
- 본문 단락은 `se-text-paragraph` 클래스를 사용해야 한다.
- 모든 `<table>`에 `table-layout:fixed`가 있어야 한다.
- 프로필 표의 레이블 셀은 `width:22%`를 사용해야 한다.
- 행사 유형 표의 헤더 왼쪽 셀은 `width:28%`, `width:30%`, `width:32%` 중 하나를 사용한다.
- 대제목은 30px, `#111111`, `<b>` 형태인지 확인한다.
- 문장 끝의 `<br><br>` 후처리가 적용되었는지 확인한다.

## SEO와 구성 검토

- 인물 섭외 원고 제목에는 **`섭외`가 들어가야 한다** — 없으면 수정 요청한다.
  `[아티스트명 섭외]` 대괄호 형식은 권장이되 강제하지 않는다(2026-08-15 개정: 실측한 1위 글 13개 중 이 형식을 지킨 것은 4개뿐이었다).
- 카테고리 키워드 원고 제목은 `[메인키워드]`로 시작해야 한다.
- 제목 길이는 보지 않는다(2026-08-15 개정: 순위 재현율 50.0%로 무관했다. 1위 평균 39자, 2위 48자, 5위 35자).
- 제목에 숫자가 들어가 있으면 지적한다 — 필수는 아니지만 숫자 있는 제목이 밀리는 경향이 관찰됐다(재현율 31.9%).
- 인물명이 한글 없이 영문·숫자로만 되어 있으면 제목·도입부 첫 문장·프로필 표 이름 행에 `영문명(한글 독음)` 병기가 있어야 한다(예: `DJ PLUMM(플럼)`). 해시태그에도 한글 독음 태그가 있어야 한다. 단 파일명 슬러그와 `person_name`은 원본 영문 그대로여야 하며, 여기에 병기가 섞였으면 수정 요청한다.
- 본문 텍스트(해시태그 제외)는 **1,500자 이상**이어야 한다. 미만이면 수정 요청한다. 6,000자 초과는 지적만 하고 막지 않는다.
  (2026-08-15 개정: 종전 3,800자 하한은 잘못된 실측에 근거했고, 실제 상위 노출 문서의 중앙값은 2,117자였다. 하한 3,800자는 상위 노출 문서의 4분의 3을 막는 값이었다.)
- 도입부는 300~500자 안에서 검색 의도, 적합 행사, 섭외 경로를 제시해야 한다.
- 도입부 첫 300~500자 안에 AI 인용 가능한 답변형 문장으로 누구/무엇, 적합 행사, 섭외 경로, 비용 변수가 들어 있어야 한다.
- FAQ 5개(비용·적합 행사·신청 절차·일정 리드타임·무대 요건) 답변은 첫 문장이 결론으로 시작하고, 비용·일정·지역·공연 시간·촬영/송출 여부 등 변수를 구체적으로 설명해야 한다.
- 행사 규모·예산별 가이드 섹션이 있어야 하며, 앞 섹션과 내용이 겹치면 수정 요청한다.
- **키워드 밀도로 수정 요청하지 않는다(2026-08-15 개정).** 상위 46% / 하위 38%로 판별력이 없었고, 실제 1위 글에 밀도 10.5·9.0 도 있고 0.2·0.4 도 있었다.
  1000자당 15회를 넘는 경우만 어뷰징으로 보고 수정 요청한다.
- `섭외` 해시태그 7개 초과는 지적만 한다 — 수정 요청 사유가 아니다(2026-08-15 개정: 하위권이 오히려 더 잘 지켰다. 상위 85% / 하위 100%).
- 카테고리 키워드 원고도 같은 기준을 적용한다 — 밀도로 막지 않는다.
- 비용·일정·무대·행사 적합성·준비 항목이 **서로 다른 어휘로** 채워졌는지 본다. 같은 내용을 표현만 바꿔 반복했으면 수정 요청한다.
- 행사 담당자 관점의 독창적 해석(관객층, 무대 구성, 예산·일정 변수, 계약 전 확인사항)이 없고 일반 홍보문만 반복되면 수정 요청한다.
- 해시태그는 20개 이상을 권장하되 수정 요청 사유는 아니다(2026-08-15 개정: 상위 42% / 하위 43%로 판별력 없음).

## CTA 검토

- 에이전시명 `메이드인헤븐`이 포함되어야 한다.
- 카카오톡 오픈채팅 링크는 **반드시 `https://open.kakao.com/o/snG6VXti`** 만 사용한다. `madeinheavenagency`, `madeinheavenagency_`, `o/sJ5IH55g`, `o/squEahWg` 등 옛 URL이 본문에 남아 있으면 실패 처리한다.
- **명함 `<img>` 태그가 본문에 들어 있으면 실패 처리한다.** 새 구조에서는 모아보기가 명함을 자동 합성하므로 본문에 직접 넣으면 중복된다.
- `data:image/...` 또는 `src="image.png"` 같은 상대 경로가 있으면 실패 처리한다.

## 최종 보고 형식

검토 결과는 아래 형식으로 남긴다.

```md
## 검토 결과

판정: 통과 / 수정 필요

### 수정 필요 항목
- 항목:
- 위치:
- 수정 방향:

### 검수 수치
- 본문 텍스트 글자수(해시태그 제외):
- `섭외` 밀도 (회/1000자):
- `섭외` 포함 해시태그 개수:
- 유튜브 iframe 개수:
- 본문 이미지 개수:
- 이미지 출처 표기 개수:
- 이미지 src 업로드 상태:
- 해시태그 개수:
```
